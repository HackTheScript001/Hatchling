Diagnostics and feature switching for Ford-family cars (Ford, Lincoln, Mercury, Mazda) using a switched ELM327 USB adapter.

**Download `Hatchling-Setup-1.0.0.exe` below** and run it. Windows may show "Windows protected your PC" because the installer isn't code-signed - click **More info**, then **Run anyway**.

- Read and clear fault codes in every module
- Live data and gauges
- Turn features on or off, with a check that the hardware is fitted and automatic backups
- Shared feature library - install features other owners have learned on the same car
- Import your car's factory As-Built file from Ford so you can always undo changes

**Use at your own risk.** Hatchling writes to your car's modules. Keep a battery charger connected when making changes, and import your factory file before changing anything.
